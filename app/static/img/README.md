# Directorio de recursos estáticos - Imágenes

Coloca aquí el archivo del logotipo oficial de ADEP:

- Nombre del archivo: `logo-adep.png` (o .jpg, .svg)
- Ruta completa: `app/static/img/logo-adep.png`
- Referencia en el código: `url_for('static', filename='img/logo-adep.png')`

El logotipo se mostrará automáticamente en:
1. Encabezado de todas las pantallas (parte superior izquierda)
2. Pantalla de inicio de sesión (/login)
3. Pantalla de registro de correspondencia (/registrar)

No modifiques el diseño, colores ni proporciones del logotipo original.
